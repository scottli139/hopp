Manage Environments 对话框 · 重设计原型

问题：背景灰白混杂、大片空白、按钮散落四处、名称栏误导、类型下拉与整体风格割裂。以下为静态原型（hover 态以批注形式固定展示）。
1背景分层：对话框主区纯白（--bg），左侧列表用 --surface 浅灰 + 右边线，两级层次不再混杂。
2布局收紧：名称从「浮空的输入框」改为行内可编辑标题（hover 才显边框）；「Add Variable」从底部孤岛改为紧跟表格的虚线行；空状态居中引导。
3按钮归位：底部一条通栏 footer——左侧放 {{key}} 用法提示，右侧 Cancel（ghost）+ Save（primary）；删除环境收进标题行右侧的 danger-hover 图标。
4表格降噪：单元格输入框默认无边框，hover/focus 才出现；行删除按钮 hover 才显示；表头统一 10px 大写字母标。
5类型徽章化：string = 中性灰徽章，secret = 琥珀徽章（warning-soft）带锁图标，替代风格割裂的 boxed 下拉。
6侧栏语义：环境列表加分组标签，当前激活环境带绿点；Globals 固定在最底部独立分组，名称只读、附说明文字。
