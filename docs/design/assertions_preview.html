M8.4 · 轻量断言 + CLI/CI 导出

F4.1 断言编辑与 Tests 结果 · F4.4 Export for CLI 与 hopp run · 2026-08-28 需求澄清确认（F4.2 AI 生成挪 M8.5）
1断言 = 声明式规则：目标（Status / Header / Body / JSONPath / Response time）+ 操作符 + 期望值 + 启用开关，零代码；期望值支持 {{var}} 插值。
2操作符按目标过滤：如 Status code 只有比较类；Header/Body 有 contains/regex；JSONPath 有 exists。右侧菜单标注各目标可用集。
3结果在响应区 Tests 页签：Send 后自动求值、不阻断；摘要栏 n/m passed 徽标（全过绿 / 有失败红）；失败行展开 expected vs actual；禁用行显示 skipped。
4存储请求级：随请求持久化（Hive 追加字段，存量兼容）；不做集合级默认断言（F4.3 批量运行再议）。
5Export for CLI：不单列菜单入口——复用现有 Export 对话框，加格式选项（Postman v2.1 / Hopp CLI .hopp.json），与 Import 合并决策同原则；原生格式全保真（含断言/预请求链/Auth；isSecret 值置空，CLI 用 --env-var 注入）。
6hopp run：cli/ Dart 子包复用求值引擎，顺序执行 + 预请求链 + 断言；任一失败 exit 非零；--reporter json|junit 输出 CI 报告。
