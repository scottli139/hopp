M8.9 · Tier 2 BYOK 云端

F9.9 云端增强：自带 Key（BYOK）+ 应用级 AES 加密存储 + 首次外发隐私门 · 默认关闭，永不自动外发 · 2026-09-07 澄清确认 · 需求与验收见 docs/PRD.md F9.9
1Provider 预设分两组：本地组（Ollama / LM Studio，标「数据不出机器」）+ 云端组（OpenAI / DeepSeek / Anthropic / 自定义，标「数据将外发」warning 色）。选中云端预设自动填官方 OpenAI 兼容端点；Anthropic 走其官方 OpenAI 兼容层 https://api.anthropic.com/v1，不引第二套客户端。
2API Key 复用应用级 AES 加密：与 F8.4 敏感变量同一方案（box_encryption 的应用级 key + HiveAesCipher），新建加密小 box 按预设分槽互不覆盖，不引 flutter_secure_storage、零新依赖；输入框只写不读——保存后界面只显示「已加密保存」，重新输入即覆盖。旧版本 AppSettings.aiApiKey 明文升级时一次性迁移并清除。诚实边界：防直接翻看数据文件，不防整机级攻击。
3首次外发隐私门：云端 Provider 第一次实际调用前弹确认（三个能力入口 + 设置对话框「检查连接」统一过这道门）；列明外发内容与目标端点，「理解并同意外发」才放行；按 Provider 记录一次，设置里可「重置隐私确认」。
4运行时指示：AI 任务对话框标题区常驻 provider chip——云端「☁ OpenAI · 数据外发」warning 色 / 本地「⚲ Ollama · 本地处理」neutral 色，每次调用外发状态一眼可辨。
5底座不动：单一 OpenAI 兼容客户端 / 超时 5s·60s / 温度 0 / 元数据-only 日志全部沿用 M8.5；云端预设时 Key 必填校验，401 →「Key 无效或未配置」、429 →「配额不足或限流」单独文案。
6本期不做：流式输出（F9.6 排 M8.10）、/v1/models 模型列表拉取（模型名仍手填）、多 Key 管理 / 用量统计、代理配置、通用聊天面板。
