②响应 Body：epoch 人性化注解

JSON 响应中 10/13 位整数命中 epoch 范围（2001–9999）时，行尾追加灰色注释显示本地可读时间；字符串内的数字不标注；工具栏开关控制；Copy 始终复制原始报文，Raw 视图不标注。

设计要点 / 边界
  • 失败语义不变：非法 offset / 单位 / 非数字输入 → 管道失败，保留 {{…}} 原文并 UI 标红，不静默发送错误值（沿用 F8.3）。
  • 单位约定：date_add 单位 s/m/h/d/w（分/时/天/周），必须带单位；date_floor 单位 hour/day/week/month，本地时区（week=本周一零点）。
  • 秒/毫秒自适应：输入 10 位按秒、13 位按毫秒解析，输出保持同单位。
  • 注解仅渲染层：性能模式用富文本 span 追加，Full 模式注入 CodeField 显示文本；原始报文、Copy 内容、断言取值一律不受影响；字符串内数字、数组下标等不标注。
  • 防误判：仅当 Body 判定为 JSON 且数值落在 2001–9999 年才标注；工具栏开关默认开，关闭后完全不参与渲染。
