F8 预请求链与变量转换 · UI 原型（M8.2）

范围：F8.1 认证配置 → F8.3 变量转换（全量算法含 aes/hmac）→ F8.2 预请求链（请求级 + 集合级 + 401 自动重跑 + 敏感变量加密存储）。静态原型，hover / 弹层态以固定展示 + 批注呈现。落地顺序见 docs/DEVELOPMENT_PLAN.md v0.8.0 M8.2。
1Auth Tab 填实（F8.1）：现为「Coming soon」占位，改为左类型列表 + 右表单。类型：Inherit（继承集合，默认）/ No Auth / Bearer Token / Basic Auth / API Key。secret 字段复用环境管理器的 eye 脱敏。
2转换管道可见化（F8.3）：{{password | sha1}} 在字段里渲染成分段 chip（变量名 = brand 色、管道函数 = warning 色虚线分隔），一眼看清「谁在起作用」；hover 弹出解析预览，逐段显示原始值 → 各步转换 → 最终发送值；| 触发函数插入菜单，带参函数（aes/hmac）弹参数小表单。
3前置链编辑器（F8.2）：请求编辑器新增第 6 个 tab「Pre-request」。每个步骤 = 从 collection 选一个已保存请求 + 提取规则表（Body JSONPath / Header / 正则 → 目标变量）；步骤可排序、可停用；产出变量写入本地作用域，不污染环境。
4运行策略与试运行：底部策略条——token 过期「手动重跑」/「401 自动重跑」开关；「试运行」面板就地执行前置链，展示产出的变量与脱敏值，不用真的发目标请求。
5集合级前置链与 Auth 继承：Collection 设置页新增「Auth & Pre-request」，集合配一次，其下请求默认 Inherit；请求级可覆盖。
6敏感变量加密存储：UI 脱敏（圆点 + eye）已随环境管理器落地，本期补存储层加密（Hive 中 secret 值加密落盘），原型界面上以锁图标标识。
