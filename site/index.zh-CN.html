快速开始

快速上手

开发与构建 Hopp 所需的环境和命令。

前置要求

  • Flutter 3.27+
  • Dart 3.6+
  • FVM（推荐用于版本管理）

开发环境

# 克隆仓库
git clone https://github.com/scottli139/hopp.git
cd hopp

# 安装 FVM（如尚未安装）
dart pub global activate fvm

# 使用项目指定的 Flutter 版本并安装依赖
fvm use
fvm flutter pub get

# 在 macOS 上运行
fvm flutter run -d macos

构建

# 构建 macOS / Windows / Linux 版本
fvm flutter build macos --release
fvm flutter build windows --release
fvm flutter build linux --release
🇨🇳 中国大陆开发者可配置 Flutter 国内镜像加速下载，详见 README。
架构

清晰的分层设计

在表现层、状态层、领域层与数据层之间保持清晰边界。

🎨

表现层

Screens 与可复用 Widgets 负责渲染 UI。

🧭

状态层

Riverpod providers 与 notifiers 管理异步状态。

🧩

领域层

Freezed 模型与业务服务。

💾

数据层

Hive、SharedPreferences 与 Dio 负责存储和网络。

项目结构

hopp/
├── lib/
│   ├── models/          # 数据模型 (Freezed + Hive)
│   ├── providers/       # Riverpod 状态管理
│   ├── services/        # HTTP 与存储服务
│   ├── widgets/         # UI 组件
│   ├── screens/         # 应用页面
│   ├── utils/           # 工具类
│   └── l10n/            # 国际化
├── macos/               # macOS 平台代码
├── windows/             # Windows 平台代码
├── linux/               # Linux 平台代码
├── test/                # 单元与 Widget 测试
└── docs/                # 文档
