③ARB 组织约定（沿用 模块_名称 命名 + 插值 placeholder）

两个 ARB 文件 key 全量对齐；带动态内容的用 placeholder，禁止代码里拼字符串。
// app_zh.arb
{
  "settings_language": "语言",
  "settings_languageHint": "界面显示语言，切换即时生效",
  "common_systemDefault": "跟随系统",
  "response_itemsCount": "{count} 项",
  "@response_itemsCount": { "placeholders": { "count": { "type": "int" } } },
  "error_requestFailed": "请求失败：{reason}"
}
// app_en.arb（同 key）
{
  "settings_language": "Language",
  "response_itemsCount": "{count} items",
  "error_requestFailed": "Request failed: {reason}"
}
设计决策（2026-09-03 澄清确认）/ 边界
  • 默认语言：system 跟随系统（OS 是中文 → 中文，否则英文）；设置对话框可覆盖为 English / 中文，即时生效 + Hive 持久化。
  • 入口唯一：只在设置对话框放语言选择，侧栏底栏不增常驻元素。
  • 抽取范围：用户可见字符串全量进 ARB——界面文案 + services/providers 的用户可见错误与提示消息；代码注释、日志、test-mode 指令协议（英文）不动。
  • AI prompt 固定中文：发给模型的 prompt 模板本期不做双语；AI 按钮/状态/错误提示等界面文案随界面语言。
  • CLI 不动：hopp run 输出维持英文（CI 场景约定）。
  • 不翻译数据：URL、Header 名、变量名、collection/请求名称等用户数据一律不翻译。
  • 测试策略：widget 测试统一到英文 locale 下用英文串查找（~60 处中文 finder 集中改 6 个文件）；新增 localeProvider 单测 + 双语言 test-mode 截图审计。
