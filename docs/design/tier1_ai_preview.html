M8.5 · Tier 1 本地 AI 模型

F9 本地模型（Ollama / LM Studio）+ F4.2 AI 生成断言 · 三个任务型弹窗 + 一个设置对话框 · 非流式 v1，无通用聊天面板 · 2026-08-31 · 需求与验收见 docs/PRD.md F9 / F4
1三个入口，各自触发一个任务弹窗：Response info bar 右侧 ✨ = 解释响应；Assertions 页首「✨ AI 生成」= 生成断言；URL 栏 Method 左侧 ✨ = 自然语言建请求。
2非流式任务型弹窗：v1 不做通用聊天面板；生成期间显示加载进度文案（本地模型可能需要 10–30 秒），结果一次性呈现，可重新生成。
3配置存 AppSettings：启用开关 / Provider 预设 / Base URL / Model / API Key 全局一份；Key 输入框为 Tier 2 云端铺路，本地模型留空即可。
4防脑补 schema 校验：AI 返回的断言先过校验，非法字段就地修正并在该行标注「已修正」；无法修正的条目直接丢弃，不臆造取值。
5AI 相关按钮统一 brand-soft 软按钮 + ✨ 图标：页首用 .btn-soft 文字按钮；URL 栏 / info bar 空间受限处用 ✨ icon-btn 高亮态（brand-soft 底 + brand 图标）。
