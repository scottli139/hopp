Hopp · M8.3 OpenAPI/Swagger 导入 · UI 原型

对应 docs/PRD.md F9.4（2026-08-28 澄清确认）· 导入流程四屏：入口 → 预览选择 → 冲突解决 → 结果报告
1规格与格式：OpenAPI 3.0.x / 3.1 + Swagger 2.0（解析层内部转 3.0 模型），JSON + YAML。
2双来源：本地文件（拖入/选择）+ URL 拉取，URL 可配一组自定义请求头（私有 spec 的 token/basic）。
3组织方式：info.title → collection 名；tags → 子集合；请求名取 summary → operationId → METHOD /path。
4防脑补取值：servers[0] → {{baseUrl}} 集合变量；path 参数 → {{id}} 空占位；query/header 取值优先级 example → default → enum[0] → 留空；body 无 example 时按 schema 生成骨架并在报告中标注。
5Auth：bearer / basic / apiKey → 集合级 Auth（secret 留空）；OAuth2 不自动配置，报告提示。
6预览后落库：按 tag 分组勾选 + 搜索过滤；冲突复用 Postman 四策略。
7不在本期：cURL 生成（F1.10）拆独立任务；spec 变更不保持联动（重导入 = 新建或走冲突策略）。
